## 🎉 Basketball & Volleyball Scoreboard v1.0.0

### ✨ New Features
- **Basketball player stats tracking** - Individual points, rebounds, assists, steals, blocks, fouls
- **Volleyball player stats tracking** - Individual points, blocks, aces, digs, assists, fouls
- Player selection UI in SCORE tab for both sports
- Visual foul warnings and auto foul-out indicators
- Box score export (PDF/Excel for basketball, CSV for volleyball)
- Automatic update system via GitHub Releases

### 🏀 Basketball Mode
- Select player to attribute points and stats
- Track rebounds, assists, steals, blocks, field goals
- Personal fouls with auto foul-out at 6 fouls
- Shot clock and game clock management
- Full/20-second timeouts

### 🏐 Volleyball Mode  
- Select player to score points
- Track blocks, aces, digs, serve assists
- Personal fouls with auto foul-out at 5 fouls
- Set management (best of 3/5)
- 2 timeouts per team per set

### 📊 Common Features
- Dark hardware scoreboard aesthetic
- Touch-friendly control panel
- Separate TV display window
- Team roster management
- Automatic data persistence
- Liga/tournament management
- Undo functionality

### 📥 Installation
1. Download `Basketball Scoreboard Setup 1.0.0.exe`
2. Run installer
3. Launch from Start Menu

### 💻 Requirements
- Windows 10/11
- 500 MB disk space
