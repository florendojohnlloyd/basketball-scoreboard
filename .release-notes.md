## 🎉 Initial Release - Basketball & Volleyball Scoreboard

### Features
✅ Full basketball scoreboard with comprehensive player stats tracking  
✅ Full volleyball scoreboard with complete player stats tracking  
✅ **NEW**: Individual player points, fouls, blocks, aces, digs, and assists for volleyball  
✅ Box score export (PDF/Excel for basketball, CSV for volleyball)  
✅ **Automatic update system** via GitHub Releases  
✅ Touch-optimized control panel  
✅ Professional scoreboard TV display  
✅ Team/player roster management  
✅ Liga/tournament management  

### 🏐 Volleyball Player Stats (NEW in v1.0.0)
- Track individual player points, fouls, blocks, aces, digs, assists
- Auto foul-out at 5 fouls
- Visual indicators for foul warnings (color-coded)
- Full box score view with CSV export
- Select player to attribute points and stats during live match

### 🔄 Auto-Update
This version includes automatic update checking. When a new version is released, you'll see a notification to download and install.

### 📥 Download & Install
1. Download `Basketball Scoreboard Setup 1.0.0.exe` below
2. Run the installer
3. Launch the app from your Start Menu or Desktop

### System Requirements
- Windows 10/11
- 500 MB free disk space
- .NET Framework (automatically installed if needed)

### 🎯 Key Features Breakdown

#### Basketball Mode
- Player points, rebounds, assists, steals, blocks
- Field goal percentage tracking
- Personal fouls with auto foul-out (6 fouls)
- Shot clock and game clock
- Timeouts (full & 20-second)
- Period/quarter management
- Detailed box score export (PDF/Excel)

#### Volleyball Mode
- Individual player scoring
- Blocks, aces, digs, serve assists
- Foul tracking with auto foul-out (5 fouls)
- Set management (best of 3/5)
- Serving team indicator
- Timeouts (2 per team per set)
- CSV box score export

#### Common Features
- Dark hardware scoreboard aesthetic
- Touch-friendly control panel
- Separate TV display window
- Team roster management
- Automatic data persistence
- Undo functionality
- Professional tournament management
