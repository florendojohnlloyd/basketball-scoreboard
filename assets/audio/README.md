# Audio Assets

Place the following audio files here:

- `horn.mp3` — End-of-period horn sound (1.5s)
- `whoosh.mp3` — Replay transition effect
- `alert.mp3` — Player foul-out alert (short beep)

These files are NOT auto-generated. Supply your own .mp3 files.
Volume is controlled via Settings (0-100%, default 80%).
