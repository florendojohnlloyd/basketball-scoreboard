# Volleyball UI: Timer removal and TV button addition

Removes the game clock/timer from the volleyball control panel and TV display, adds a TV button to open the scoreboard window, and introduces optional set score history tracking. The changes correctly address the user's requirement that volleyball does not use a game clock.

**Watch for:** None — all expected changes are present and correct.

**Verdict**: APPROVED

## High-level view

The timer UI components (clock display, start/stop controls) are cleanly removed from both the control panel center section and the TV scoreboard layout. No orphaned references to `gameClock` or `clockDisplay` remain in the volleyball-specific files.

The TV button is wired correctly to the IPC invoke that opens the scoreboard window and is positioned in a 5-column action row as specified.

The SET badge font size increased from 2.8rem to 4.5rem, making it significantly more prominent in the control panel.

The `setScores` field added to `VolleyballState` is optional, allowing backward compatibility with existing game states.

## Timer UI removal from control panel

VolleyballScoreTab.tsx previously had a center panel in the top banner showing a clock display with start/stop buttons. That entire section is now gone. The top banner grid changed from 4 columns (`1fr auto auto 1fr`) to 3 columns (`1fr auto 1fr`), removing the clock column. The center now shows only the SET badge with enlarged font (4.5rem, up from 2.8rem).

No timer control imports or timer-related state references remain in the file.

## Timer removal from TV scoreboard

VolleyballScoreboardLayout.tsx no longer destructures or references `gameClock` from the game state. The live scoreboard section previously had a `.vb-center-time-box` div between the score displays; that element is removed entirely from the JSX.

The import statement `formatClockDisplay` from `clockUtils` is absent (grep confirmed zero matches). The only clock utility imported is `formatClockPrecise`, which is used exclusively for the timeout countdown overlay — a distinct concern unrelated to game clock.

No orphaned variables or unused imports remain.

## TV button in action row

The action row grid changed from `repeat(4, 1fr)` to `repeat(5, 1fr)`, adding a fifth column. The new button labeled "📺 TV" is positioned between UNDO and RESET.

The button's onClick handler invokes:
```tsx
window.electron.ipcRenderer.invoke('scoreboard:query', { type: 'OPEN_SCOREBOARD' })
```

This matches the standard IPC pattern for opening the scoreboard window.

## SET badge prominence

The SET badge in VolleyballScoreTab.tsx now uses `fontSize: '4.5rem'` (previously 2.8rem). The badge sits in the center column of the top banner and displays `SET {currentSet}` in LED amber styling with increased padding and border emphasis.

## Optional set score history

The `VolleyballState` interface in types.ts adds:
```typescript
setScores?: Array<{ set: number; homeScore: number; awayScore: number }>;
```

The field is optional (marked with `?`), allowing volleyball game states created before this change to remain valid. The field is not yet consumed by UI or reducer logic, but the data structure is in place for future set-by-set history display.
